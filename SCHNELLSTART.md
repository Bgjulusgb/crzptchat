# 🚀 QUICK START - Secure Chat

## ⚡ Schnellstart in 3 Schritten

### 1️⃣ Server starten
```powershell
python chat_server.py
```
✅ Server läuft auf: **http://localhost:5000**

### 2️⃣ Browser öffnen
```
http://localhost:5000
```

### 3️⃣ Account erstellen & Chatten
1. **Registrieren** klicken
2. Benutzername, Email, Passwort eingeben
3. **Los chatten!** 🎉

---

## 💻 Alternative: CLI-App

```powershell
python secure_chat_app.py
```

Dann:
1. Option **1** - Registrieren
2. Option **2** - Anmelden
3. Option **3** - Nachrichten senden
